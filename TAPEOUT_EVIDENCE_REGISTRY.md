## Evidence rules

1. A hash identifies the exact artifact; it does not prove the claim inside it.
2. `EXPERIMENTAL` evidence can support a decision but never a stage completion or signoff.
3. Logs regenerated by a run are hashed only after the run is frozen.
4. Stale or contradictory evidence is retained and marked, never deleted.
5. New evidence gets the next EV ID; existing IDs are never reused or renumbered.
