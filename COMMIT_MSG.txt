RTL fixes (both found by Verilator's unique-case checking, both would have
aborted any simulation that touched the affected register):
- rtl/rtl_peripherals/timer.sv: the write-path `unique case (paddr[11:2])`
  had no `default` and did not list STATUS (0x0C), so writing TIMER_STATUS
  aborted the simulation. Added the RW1C write arm and a default.
- rtl/rtl_peripherals/gpio.sv: the write-path `unique case` had no `default`
  and did not list DATA_IN or INT_PEND, so writing those offsets aborted
  the simulation. Added a default.
