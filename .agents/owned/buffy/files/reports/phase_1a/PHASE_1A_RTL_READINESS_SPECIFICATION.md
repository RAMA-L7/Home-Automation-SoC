# Phase 1A RTL Readiness Specification

The following minimum architecture specifications must be finalised and approved before any RTL development can begin.  Each item references the relevant ARC decision(s) and evidence source(s).  Absence of any item constitutes a missing prerequisite.

## 1. Processor Configuration
- **Core:** Ibex (lowRISC) configured for **RV32IMC** (ISA extensions: Integer, Multiply, Compressed).  Exact configuration string: v32imc (no extensions beyond C).  
- **Evidence:** DS‑01 Sec. 1, DS‑02 Sec. 1 (VERIFIED).
- **Decision ID:** ARC‑001 (PENDING APPROVAL).

## 2. Bus & Interconnect
- **CPU‑to‑Memory Bus:** AXI4‑Lite master, generated by ibex_axi_bridge (LiteX).  
- **Peripheral Bus:** APB (via LiteX pb_bridge).  
- **Adapter Architecture:** Ibex req/gnt → AXI4‑Lite → APB bridge (ARC‑011, ARC‑012).  
- **Evidence:** DS‑02 Sec. 5, DS‑01 Sec. 2.
- **Decision IDs:** ARC‑002, ARC‑011, ARC‑012 (PROPOSED).

## 3. Memory Map (32‑bit)
- **Boot ROM:** 0x0000_0000 – 0x0000_3FFF (16 KB).  
- **TCM:** 0x0001_0000 – 0x0001_7FFF (32 KB).  
- **SRAM:** 0x2000_0000 – 0x2001_FFFF (128 KB).  
- **QSPI Flash:** 0x4000_0000 – 0x43FF_FFFF (64 MB).  
- **APB Peripherals:** 0x5000_0000 – 0x500F_FFFF (1 MB).  
- **Interrupt Controllers:** 0x8000_0000 – 0x8000_FFFF (PLIC/CLINT).  
- **Evidence:** ARC‑019, ARC‑020, DS‑01 Sec. 3, DS‑05 Sec. 11.
- **Decision IDs:** ARC‑019, ARC‑020 (PROPOSED).

## 4. SRAM & TCM Interfaces
- **SRAM Macro:** OpenRAM generated 128 KB, 16‑bit data width, synchronous interface with optional ECC (disabled for now).  
- **TCM:** Directly connected to Ibex pipeline, no bus, zero‑wait latency.  
- **Evidence:** DS‑05 Sec. 11 (OpenRAM), DS‑01 Sec. 4.
- **Decision IDs:** ARC‑003 (Memory map), ARC‑010 (handshake signals).

## 5. QSPI Flash Controller
- **Controller:** OpenSPI QSPI controller, 4‑bit double‑data‑rate mode, memory‑mapped to AXI4‑Lite address space.
- **Boot ROM Access:** Direct read from flash for OTA image verification.
- **Evidence:** DS‑01 Sec. 4, DS‑04 Sec. 6.
- **Decision ID:** ARC‑018 (Boot flow) – PROPOSED.

## 6. Peripheral Register Interfaces
- **Register Width:** 32‑bit, APB‑aligned, with standard READ/WRITE/SET/CLEAR registers.
- **Clock Gating:** Each peripheral has a local enable controlled by the power‑domain controller (ARC‑006).
- **Evidence:** DS‑02 Sec. 5, DS‑01 Sec. 4.
- **Decision IDs:** ARC‑005, ARC‑006.

## 7. Interrupt Architecture
- **Interrupt Controller:** PLIC for external peripherals, CLINT for timer & software interrupts.
- **Priority Scheme:** 7‑bit priority, pre‑emptive handling.
- **Evidence:** DS‑01 Sec. 5.
- **Decision ID:** ARC‑014.

## 8. Clock & Reset Domains
- **Clock Domains:** Core (1 V, 50 MHz), IO (1.8 V, up to 25 MHz), Always‑On (3.3 V, 32 kHz).  
- **Reset Signals:** Global active‑low eset_n, core‑local reset, peripheral reset registers.
- **PLL:** Integer‑N generating 50 MHz from 12 MHz crystal.
- **Evidence:** ARC‑006, ARC‑007, DS‑02 Sec. 3‑4.
- **Decision IDs:** ARC‑006, ARC‑007.

## 9. Power‑Management Interfaces
- **PMIC:** TPS65217 – Buck converters for Core (1.0 V) and IO (1.8 V), LDO for AON (3.3 V).  I²C‑controllable sequencing.
- **Power‑Loss Detection:** PMIC ALERT pin monitors VDD_CORE dropout; backup regulator supplies always‑on domain (10 mA).  
- **Evidence:** ARC‑028, ARC‑029, DS‑06 Sec. 2.
- **Decision IDs:** ARC‑009, ARC‑028, ARC‑029.

## 10. Secure Boot & Key Storage
- **Secure Boot ROM:** 16 KB, verifies signed image using RSA‑2048/ECDSA.
- **Crypto Engines:** AES‑256, SHA‑256, TRNG.
- **Key Provisioning:** Device‑unique key generated by TRNG, stored in OTP/fuse region; used by boot ROM.
- **Evidence:** ARC‑025, ARC‑026, DS‑04 Sec. 6.
- **Decision IDs:** ARC‑025, ARC‑026, ARC‑033.

## 11. Debug Interface
- **Supported Debug:** JTAG (TCK, TMS, TDI, TDO) and optional SWD (SWCLK, SWDIO).  Both accessible via 6‑pin header.
- **Evidence:** ARC‑024, DS‑06 Sec. 3.
- **Decision ID:** ARC‑032.

## 12. Top‑Level Pin Requirements
- **Package:** QFN‑64, 40 usable I/Os.
- **Pin Assignment:** As defined in EXTERNAL_INTERFACE_AND_PINOUT.md (ARC‑023).
- **Evidence:** DS‑06 Sec. 2.
- **Decision ID:** ARC‑022, ARC‑023.
