# Clock, Reset and Power Architecture

## 1. Clocking Strategy (DS‑02 Section 3)
- **Primary PLL**: Integer‑N PLL generates 50 MHz core clock from 12 MHz crystal (OpenPLL – UNKNOWN but assumed viable).
- **Low‑Power Oscillator (LPO)**: 32 kHz RC oscillator supplies always‑on domain for wake‑up timers (DS‑02 Section 3).
- **Clock Domains**:
  - **Core Domain** (1.0 V, 50 MHz) – Ibex, memory controllers.
  - **Peripheral Domain** (1.8 V, up to 25 MHz) – UART, SPI, I²C, GPIO.
  - **Always‑On Domain** (3.3 V) – LPO, watchdog, PMIC I²C communication.
- **Clock Gating**: Glitch‑free enable cells inserted per peripheral (DS‑02 Section 2 – VERIFIED).

## 2. Reset Architecture (DS‑02 Section 4)
- **Power‑On Reset (POR)**: Multi‑stage reset generator distributed from PMIC to core and peripherals.
- **Core‑Local Reset (CLINT)**: Provides timer‑based reset for the CPU.
- **Peripheral Reset**: APB‑controlled reset registers allow software‑initiated peripheral resets.

## 3. Power Domains (DS‑05 Section 3 & DS‑06 Section 2)
- **AON (Always‑On) Domain** – 3.3 V supplied by PMIC LDO, hosts LPO, watchdog, and I²C bus for PMIC control.
- **Core Domain** – 1.0 V generated by buck converter (TPS65217) feeding CPU and SRAM.
- **IO Domain** – 1.8 V LDO for peripheral I/O levels.
- **Power Gating**: Optional for high‑current blocks (e.g., external RF modules) via PMIC switches (ASSUMED).

## 4. Power Management IC (PMIC) (DS‑06 Section 2)
- **Chosen PMIC**: TI TPS65217 (VERIFIED). Provides 3 buck converters (1.0 V, 1.8 V, 3.3 V) and 2 LDOs. I²C‑addressable configuration allows programmable sequencing.
- **Sequencing**: AON domain powers up first, followed by core and IO domains.
- **Risks**: Peak current transients for FPGA/ASIC may exceed 1 A per buck; design margins required (PENDING APPROVAL).

## 5. Evidence Summary
- Clocking, PLL, and gating concepts are described in DS‑02 Section 2‑3 (VERIFIED/ESTIMATED).
- Power domain definitions follow SkyWater 130 nm design practices (DS‑05 Section 3, DS‑06 Section 2).
